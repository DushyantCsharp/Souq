- [from workers] Semantics of `souq_indexer.aimd` / `souq_indexer.routing` (implemented in services/indexer/src):
  - `AimdController(initial=1000, min_size=50, max_size=5000, additive_step=100, decrease_factor=0.5)`; `batch_size` starts at `initial` clamped to [min,max]; `on_success()` → `min(max_size, batch_size + additive_step)`; `on_rejection()` → `max(min_size, int(batch_size * decrease_factor))`; `backoff_seconds(n)` → `0.0` for n <= 0, else `min(30.0, 0.5 * 2 ** (n - 1))` (no jitter; extra kwargs `backoff_base_s=0.5`, `backoff_max_s=30.0`).
  - `classify_item_error(status, error_type)`: 2xx → "ok"; 404 with error_type None (delete of a missing doc) → "ok"; 409 or `version_conflict_engine_exception` → "conflict_ok"; 429, any 5xx, `es_rejected_execution_exception`, `circuit_breaking_exception`, `cluster_block_exception`, `unavailable_shards_exception`, `no_shard_available_action_exception`, `index_not_found_exception`, `process_cluster_event_timeout_exception`, `timeout_exception` → "retryable"; everything else (e.g. 400 `mapper_parsing_exception`, `document_parsing_exception`, `illegal_argument_exception`, `strict_dynamic_mapping_exception`) → "non_retryable".
  - `attempt` = value of the `attempt` header on the consumed message (0 on `catalog.changes`). `Route` is a frozen dataclass `Route(topic: str, not_before_ms: int | None, attempt: int)`. `next_route(0, True, t)` → `Route("catalog.retry.30s", t + 30_000, 1)`; `next_route(1, True, t)` → `Route("catalog.retry.5m", t + 300_000, 2)`; `next_route(n >= 2, True, t)` → `Route("catalog.dlq", None, n + 1)`; `next_route(n, False, t)` → `Route("catalog.dlq", None, n + 1)`. Delays come from `config/budgets.yaml` `indexer.retry_delays_s`.
